## Состояние S04

В исходной версии `c40a40d` находились паспорт и SR; архитектура, T и D добавлены следующим этапом. Здесь зафиксирована концепция безопасности. Реализация механизмов и выполнение описанных в D проверок ещё предстоят.

В [модели угроз](THREAT_MODEL.md) выбран приоритетный набор; каждая его угроза связана с SR и решением, содержащим будущую проверку. Пример для объяснения: [T-03](THREAT_MODEL.md#t-03) → SR-06 → [D-02](DESIGN_DECISIONS.md#d-02). Разбор учитывает разные жалобы на один материал, конкуренцию и частичный сбой.

До S05/EK1 нужна минимальная запускаемая основа, инструкция и фактическое подтверждение запуска зафиксированного commit. Полная реализация сценариев на этом этапе не требуется. Личный вклад M1–M3 должен быть заполнен по фактам; существующая история сама по себе не устанавливает, как результаты распределены между кодами участников.
