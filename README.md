## Состояние S05 / EK1

Концепция безопасности (SR, T, D) дополнена минимальной запускаемой основой:

- `GET /health` — проверка чтения SQLite;
- `GET /materials` — только видимые учебные материалы с ограниченной пагинацией;
- начальная схема БД с ограничениями целостности и атомарное заполнение каталога без перезаписи существующих записей;
- безопасные ответы об ошибках, документация API выключена по умолчанию;
- автоматизированные проверки реализованного объёма.

**[Окружение, команды запуска, ожидаемые ответы и выполненные проверки → PROJECT.md](PROJECT.md#run)**

Вход, создание и рассмотрение жалоб и аудит действий пока не реализованы; будущие проверки из D не выполнены.

## Материалы для защиты

В [модели угроз](THREAT_MODEL.md) выбран приоритетный набор T-01–T-05; каждая угроза связана с SR и решением, содержащим будущую проверку. Центральная цепочка: [T-03](THREAT_MODEL.md#t-03) → [SR-06](SECURITY_REQUIREMENTS.md#sr-06) → [D-02](DESIGN_DECISIONS.md#d-02). Разбор учитывает разные жалобы на один материал, конкуренцию и частичный сбой.
