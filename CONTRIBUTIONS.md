# Вклад участников

Коды `M1–M3` постоянные; соответствие кодов участникам и GitHub-аккаунтам передано через закрытую регистрацию. Этапы распределялись так: M1 — паспорт проекта и требования (S01–S02), M2 — модель угроз (S03), M3 — проектные решения (S04). Минимальную запускаемую основу (S05) команда выполняла совместно; ниже для каждого участника указана его часть. Будущие проверки из D не являются выполненными тестами и как результат не записываются.
